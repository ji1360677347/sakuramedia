# User manual

This manual starts once SakuraMedia is deployed and you can sign in, and walks you through discovery, subscription, download, import, playback and organizing. If SakuraMedia is not deployed yet, read [Quick start](/guide/quick-start) first.

The tutorials follow the page names and entry points of the desktop client. Mobile clients work for browsing and watching, but the layout and the management entry points available differ; use the desktop client when configuring the system or dealing with subscriptions and import problems in bulk.
